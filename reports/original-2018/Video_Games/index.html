训练与 SID 验证结果

全部 16,572 件商品获得唯一四 token SID。共享的语义前缀越长，商品原向量通常越相似。

留出商品 Top-10 近邻保持率：初始化 4.25% → 原始三层码 33.82% → 碰撞修复后三层码 29.21%。碰撞修复提高唯一性，也带来额外近邻损失；第一级码本使用 142/256，仍有优化空间。

第四个 token 仅区分身份，不计入语义评分；这些结果不是推荐准确率。
